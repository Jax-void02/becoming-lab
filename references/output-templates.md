## 1. 输出原则

- 使用用户自己的词，不用空泛的心理学赞美。
- 先给结论，再给支持它的事实。
- 明确标记：**确认信号 / 合理推断 / 待验证假设 / 信息空白**。
- 不用总分、雷达图或伪精确概率掩盖不可比较的张力。
- 不把复杂人生压缩成一句职业名称。
- 只保留作出下一步所需的敏感信息。
- 阶段小结控制在用户当下能够消化的长度；最终简报可以更完整。

## 2. 阶段小结

```markdown
到这里，我暂时看到三点：

1. **你已经说得很明确的：** [用户明确认领或有直接行为证据的内容]
2. **一个仍需你校正的推断：** [系统解释及其依据]
3. **目前最大的未知：** [若得到答案会改变方向的未知]

[只问一个校正或推进问题]
```

若用户纠正，明确写出更新：

```markdown
明白，我把刚才的判断改掉：不是 **[旧解释]**，而是 **[用户校正]**。这会让我们对 **[方向或未知]** 的判断发生 [具体变化]。
```

## 3. 迷茫构成图

```markdown
## 你现在卡在哪里

**主要问题：** [信息不足 / 选项过载 / 外界冲突 / 结构限制 / 承诺焦虑 / 耗竭逃离 / 信心证据不足]

**直接证据：**
- [用户原话或事实 1]
- [用户原话或事实 2]

**次要问题：** [如有]

**这次不急着解决：** [不影响当前下一步的问题]

**最值得先弄清的一个问题：** [关键未知]
```

## 4. 动机所有权图

| 类别 | 内容 | 证据 | 当前状态 |
|---|---|---|---|
| 我的声音 | [理解代价后仍愿意认领的理由] | [原话/经历] | 确认或待校正 |
| 我认领的他人声音 | [例如自愿承担的家庭责任] | [原话/行为] | 确认或待校正 |
| 尚未消化的压力 | [羞耻、比较、评价、控制] | [触发情境] | 需要继续分辨 |
| 逃离动机 | [希望结束的当前痛苦] | [具体环境] | 不等同于新方向吸引力 |

总结时使用：

> 这不是“真实愿望”和“虚假愿望”的二分。更准确地说，你已经愿意认领的是 **[内容]**，仍然像外部压力的是 **[内容]**，而 **[内容]** 目前主要是想离开旧处境，尚不能证明新方向合身。

## 5. 过程合身图

| 维度 | 当前信号 | 证据等级 | 具体经历 |
|---|---|---|---|
| 核心活动 | [分析/创造/影响/组织/维护等] | [等级] | [经历] |
| 问题类型 | [开放/明确、抽象/具体等] | [等级] | [经历] |
| 节奏 | [深度/快速迭代、单线程/多线程] | [等级] | [经历] |
| 自主程度 | [偏好] | [等级] | [经历] |
| 挑战与反馈 | [偏好] | [等级] | [经历] |
| 关系密度 | [独立/协作/对外接触] | [等级] | [经历] |
| 环境 | [稳定/变化、现场/远程等] | [等级] | [经历] |
| 恢复方式 | [边界与下班后的需要] | [等级] | [经历] |

补充两栏：

- **做得好但不想长期重复：** [内容]
- **尚不熟练但愿意继续练：** [内容]

## 6. 现实账本

```markdown
## 现实不是附注

### 不可牺牲的底线
- [最低收入/健康/睡眠/安全/地域/照护等]

### 已核实的硬约束
- [事实 + 来源/日期]

### 可协商约束
- [可以通过顺序、时间、地点、合作方式改变的限制]

### 信息空白
- [可能改变决定、尚需查证的信息]

### 可用资源
- [技能证据、作品、学历、关系、时间、资金、迁移经验]

### 支持与受影响的人
- [支持者、共同承担者、会被决定影响的人]
```

## 7. 方向假设卡

为每个方向分别生成：

```markdown
## 方向假设 [A]：[短名称]

> 在未来 6–12 个月，我想优先探索 **[问题、对象或领域]**，主要通过 **[具体活动]**，在 **[偏好的环境与关系]** 中工作，因为它较可能满足我对 **[需要]** 的重视。我的底线是 **[不可补偿条件]**。目前最大的未知是 **[需要验证的问题]**。

**为什么值得靠近**
- [用户认领的动机]
- [直接活动证据]

**现实基础**
- [资源、支持、进入条件]

**当前张力**
- [两项不能简单合并的需要或代价]

**什么会推翻它**
- [明确反证]

**证据状态**
- 确认信号：[内容]
- 合理推断：[内容]
- 待验证假设：[内容]
- 信息空白：[内容]
```

至少让两个方向代表不同生活逻辑。例如：

- 优先探索与高成长；
- 优先稳定与生活空间；
- 在现路径中重构工作方式；
- 通过桥接路径保留选择权。

不要为了凑数量生成缺乏现实基础的选项。

## 8. 压力测试记录

```markdown
| 测试 | 当前回答 | 对假设的影响 |
|---|---|---|
| 过程—结果 | [内容] | 增强 / 削弱 / 不确定 |
| 吸引—逃离 | [内容] | 增强 / 削弱 / 不确定 |
| 普通代价 | [内容] | 可接受 / 触底 / 待核实 |
| 困难以后 | [内容] | 增强 / 削弱 / 无证据 |
| 反证 | [内容] | 可验证性是否足够 |
| 可逆性 | [门/桥/悬崖] | 下一步承诺大小 |
```

不要汇总成总分。用一句话写出：

> 目前最有区分力的不是哪项分数更高，而是 **[关键张力或未知]**。

## 9. 七天实验卡

```markdown
# 本周方向实验

**对应方向假设：** [A/B/C]

**要验证的唯一未知：**
[能够被行动更新的问题]

**实验动作：**
[真实任务/访谈/观察/短项目]

**完成时间：**
[日期、时段、预计时长]

**事前预测：**
- 我预计最有能量的部分：[内容]
- 我预计最抗拒或痛苦的部分：[内容]
- 我预计结束后会：[更想靠近/保持距离/仍未知]

**观察指标：**
- 开始前的抗拒来自什么；
- 过程中何时投入；
- 困难后好奇是否仍在；
- 结束后的能量与继续意愿；
- 实际时间、技能缺口、环境与成本。

**if–then 计划：**
如果 [最可能的障碍]，那么我先 [15 分钟最小动作]。

**更新规则：**
- 若 [结果]，增强假设；
- 若 [结果]，削弱假设；
- 若 [结果]，推翻或改写假设。
```

## 10. Reality interview 记录

```markdown
## 现实访谈记录

**受访者位置：** [阶段/岗位/团队类型，不记录不必要身份]

**事实信息：**
- [普通任务、节奏、要求、退出路径]

**个人体验：**
- [受访者的偏好与感受；不要当总体事实]

**与原想象不一致：**
- [内容]

**对方向假设的更新：**
- [增强/削弱/仍未知 + 原因]

**还需交叉核实：**
- [内容]
```

## 11. 当前方向简报

```markdown
# 我的当前方向简报

> 版本日期：[YYYY-MM-DD]
> 这是一份当前证据下的工作假设，不是终身结论。

## 1. 我现在真正卡在哪里
[迷茫类型、决定期限、真正问题]

## 2. 我愿意认领的动机
- [内容 + 证据]

## 3. 比较合身的普通日常
- 核心活动：[内容]
- 节奏与反馈：[内容]
- 自主与协作：[内容]
- 工作之外需要保留的生活：[内容]

## 4. 现实边界与筹码
- 不可牺牲底线：[内容]
- 硬约束：[内容]
- 可协商约束：[内容]
- 可用资源与支持：[内容]
- 信息空白：[内容]

## 5. 当前方向假设

### A. [名称]
[一句假设 + 证据状态 + 最大未知]

### B. [名称]
[一句假设 + 证据状态 + 最大未知]

### C. [可选]
[一句假设 + 证据状态 + 最大未知]

## 6. 当前建议
[在现有证据下优先走近什么；为什么；建议强度]

**什么会改变这个建议：** [反证或新事实]

## 7. 本周实验
[引用实验卡]

## 8. 实验后回来回答
1. 开始前的抗拒来自哪里？
2. 何时最投入，何时最想结束？
3. 困难后好奇是否仍在？
4. 哪个原有想象被现实修改？
5. 下一步应增强、削弱还是改写哪个假设？
```

以以下语气结束：

> 你现在不需要保证这条路永远正确。现有证据只需要回答：它是否值得你走近一点。走近以后，你会比今天更有资格决定下一步。

## 12. 低电量简报

```markdown
# 现在先不决定人生

**目前更像：** [需要恢复 / 需要离开高损耗环境 / 需要一条事实信息 / 需要即时支持]

**今天不作的结论：**
- 不把“什么都不想要”解释为长期偏好；
- 不要求自己现在选出理想道路。

**接下来 24–72 小时只做：**
1. [减少一个负担]
2. [联系一个支持者或专业资源]
3. [若有余力，完成一个极小信息动作]

**何时再回来探索：** [状态条件，而非苛刻日期]
```

## 13. 实验后更新

```markdown
## 方向更新记录

**原假设：** [内容]

**事前预测：** [内容]

**实际观察：** [具体事实]

**不作过度解释：** [单次实验不能回答什么]

**证据变化：**
- 从待验证升级为合理推断：[内容]
- 被削弱或推翻：[内容]
- 新增信息空白：[内容]

**下一版假设：** [更新后的句子]

**下一步：** [继续靠近 / 换一种环境再试 / 暂停 / 转向另一假设]
```
